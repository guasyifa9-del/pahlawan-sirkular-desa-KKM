Berikut tata cara **ringkas 2 langkah** untuk memasukkan link Google Sheets ke dalam aplikasi game:

---

### 📌 Tahap 1: Ambil Link CSV dari Google Sheets (Hanya 1x)

1. Buka file Google Sheets soal Bapak/Ibu Guru.
2. Klik menu **File** (di pojok kiri atas) ➡️ Pilih **Bagikan (Share)** ➡️ Klik **Publikasikan ke web**.
3. Ubah kotak pilihan dari *Halaman Web* menjadi **`Nilai yang dipisahkan koma (.csv)`**.
4. Klik tombol hijau **Publikasikan** ➡️ Klik **OK**.
5. **Salin / Copy link panjang** yang muncul (ujungnya `...pub?output=csv`).

---

### 📌 Tahap 2: Tempelkan Link ke Aplikasi Game Kuis

1. Buka website **Aplikasi Game Kuis**.
2. Klik tombol **⚙️ Pengaturan** *(ikon gerigi di pojok kanan atas)*.
3. Tempel *(Paste)* link tadi pada kolom:  
   👉 **`URL Google Sheets Soal Kuis (Format CSV)`**
4. Klik tombol hijau **SIMPAN PENGATURAN**.

✨ **Selesai!** Semua soal & pelajaran di game akan otomatis terbarui dari Google Sheets.
